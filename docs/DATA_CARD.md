# Data Card — SentinelML Controlled Stream

| Field | Value |
|---|---|
| **Name** | SentinelML synthetic controlled stream |
| **Type** | Synthetic, tabular, time-ordered (1 record / simulated minute) |
| **Generator** | `src/sentinelml/ingestion/synthetic.py` (fully deterministic given `seed`) |
| **Licence** | MIT (generated by this repository) |
| **Size** | 12 000 records × 7 features + label (configurable) |
| **Task** | Binary classification — will an industrial asset raise a failure flag? |
| **Unit of observation** | One sensor reading of one asset at one timestamp |

## Schema
| Column | Type | Valid range | Notes |
|---|---|---|---|
| `timestamp` | datetime | monotonic | 60 s spacing from 2026-01-01 |
| `sensor_a`, `sensor_b`, `sensor_c` | float | [-10, 10] | correlated Gaussian sensors |
| `load_kw` | float | [0, 500] | log-normal; log-transformed in the pipeline |
| `temp_c` | float | [-40, 80] | daily seasonality + noise |
| `region` | category | north/south/east/west | site of the asset |
| `label` | int | {0, 1} | failure flag (target) |
| `concept_alpha` | float | [0, 1] | **ground truth only** — 0 = old concept, 1 = new. Never a feature. |
| `quality_fault` | bool | — | ground truth for injected quality faults |

## Injected conditions (ground truth)
* **Drift** starts at record 6 000 (batch 24). Types: sudden, gradual, incremental, recurring.
  Both the covariate distribution (sensor_a mean, sensor_c variance, load, temperature, region mix)
  and the concept (coefficients relating features to label) change.
* **Quality faults** in batches 30 and 38: 15 % nulls in `sensor_b`, impossible `temp_c = 999`,
  negative `load_kw`, an unseen region `unknown_site`, and 5 % duplicate rows.

## Real-data path
Set `source: csv` in `configs/data.yaml` and point `csv_path` at a timestamped CSV with the same
schema. Recommended public sources (check each licence before use):
* Numenta Anomaly Benchmark (NAB) — streaming anomaly replay.
* UCI Electricity Load Diagrams 2011–2014 — consumption drift.
* NYC TLC Trip Records — large-scale tabular/time data (beware future leakage).

## Known limitations
* Synthetic drift is cleaner and better separated than real drift.
* Labels are revealed one batch after prediction; real label delay is often days.
* Do **not** present results on this stream as performance on a real system.
